## Mobile Lock Prank
This is a small mobile lock screen prank app. 
It works for fingerprint locks only.

### How it works
When someone else tries to unlock your mobile device, the app will say "Put the phone down" or "Stop touching me, you are not my owner" out loud.
When it detects your fingerprint, it would just say "Welcome, Manan".

This project was built only for fun. Not meant to be published on app stores.

### Permissions required
- Notifications
- Display over other apps
